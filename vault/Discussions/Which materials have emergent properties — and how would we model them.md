# Which materials have emergent properties — and how would we model them?

*Proposed*

## Provocation

> Which material has emergent properties? Are these properties through patternation, for example: like butterfly wing diffraction gratings, anisotropic structure like femur bones and wood, Or emergent properties from system flow: sequential effector transductions, such as cellular signalling and other bio-logic? Do we understand the logic in the resultant patternation or are we relying on agent based models to elucidate linkages which we do not understand at the moment. IF we then want to build digital models such as world models, how can we think of a system extract training data. Is this the true bottle neck underpinning all biotech.
