# Chronic bioelectrodes: is the conductive-polymer route overhyped?

*Proposed*

## Provocation

> Implantable chronic bioelectrodes - currently there is a lot of focus on conductive polymers for this purpose but very little long-term stability data. The promise is that they reduce the foreign body reaction so could be used for longer but CPs themselves start degrading at similar timelines as metal electrodes cause scar tissue formation, so I believe the CP route might be vastly overhyped.
